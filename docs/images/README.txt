Tips
- Use a clear head-and-shoulders photo, roughly square (for example 600 x 600 pixels).
- Keep each photo under 300 KB so the whole site stays under the 20 MB course limit.
- Until a photo is added, the page shows a colored circle with the member number instead.
- If a photo has another type (for example .png), change its name in about.html
  (search for images/).
